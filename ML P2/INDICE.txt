CARACTERÍSTICAS Y ALGORITMOS
================================================================================

K-NN (K-NEAREST NEIGHBORS):
┌─────────────────────────────────────────────────────┐
│ Algoritmo:                                          │
│ 1. Calcula distancia a todos los puntos de entren. │
│ 2. Ordena por distancia                            │
│ 3. Selecciona los K puntos más cercanos            │
│ 4. Promedia sus salidas                            │
│                                                     │
│ Ventajas:                                          │
│ - Simple de implementar                            │
│ - No requiere entrenamiento                        │
│ - Flexible (cualquier K)                           │
│                                                     │
│ Desventajas:                                       │
│ - Lento con muchos datos                           │
│ - Sensible a K                                     │
│ - Requiere normalización                           │
└─────────────────────────────────────────────────────┘

MÍNIMA DISTANCIA:
┌─────────────────────────────────────────────────────┐
│ Algoritmo:                                          │
│ 1. Agrupa muestras por clase                       │
│ 2. Calcula centroide de cada clase                 │
│ 3. Encuentra prototipo más cercano                 │
│ 4. Retorna clase del prototipo                     │
│                                                     │
│ Ventajas:                                          │
│ - Muy rápido                                       │
│ - Pocas muestras en memoria                        │
│ - Interpretable                                    │
│                                                     │
│ Desventajas:                                       │
│ - Menos preciso que K-NN                           │
│ - Asume distribuciones simples                     │
│ - Sensible a outliers                              │
└─────────────────────────────────────────────────────┘
