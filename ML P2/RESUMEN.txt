================================================================================
FORMATO DE ARCHIVO DE DATOS
================================================================================

Formato de texto plano con separador |

Ejemplo:
    5.1,3.5,1.4,0.2 | 0
    7.0,3.2,4.7,1.4 | 1
    6.3,3.3,6.0,2.5 | 2

Características:
- Separador entrada/salida: |
- Separador valores: ,
- Líneas que comienzan con # son comentarios
- Las líneas vacías se ignoran

================================================================================
API DE PROGRAMACIÓN
================================================================================

EJEMPLO BÁSICO:

from src.dataset import Dataset
from src.knn_classifier import KNNClassifier
from src.minimum_distance_classifier import MinimumDistanceClassifier

# 1. Crear y cargar dataset
ds = Dataset(input_size=4, output_size=1)
ds.load_from_file('data/training_data.txt')

# 2. Crear clasificadores
knn = KNNClassifier(ds, k=3, distance_metric='euclidean')
md = MinimumDistanceClassifier(ds, distance_metric='euclidean')

# 3. Realizar predicciones
pred_knn = knn.predict([5.1, 3.5, 1.4, 0.2])
pred_md = md.predict([5.1, 3.5, 1.4, 0.2])

print(f"K-NN: {pred_knn}")
print(f"MD: {pred_md}")

CLASES PRINCIPALES:

================================================================================
CARACTERÍSTICAS TÉCNICAS
================================================================================

K-NN (K-Nearest Neighbors):
  • Algoritmo: Clasificación por k vecinos más cercanos
  • Complejidad temporal: O(n*d) por predicción
  • Complejidad espacial: O(n*d)
  • K ajustable: 1 a N (tamaño del dataset)
  • Métricas: Euclidiana, Manhattan
  • Predicción: Promedia salidas de k vecinos

Mínima Distancia:
  • Algoritmo: Clasificación por prototipo más cercano
  • Complejidad temporal: O(k*d) por predicción
  • Complejidad espacial: O(k*d)
  • Prototipos: Calculados automáticamente
  • Métricas: Euclidiana, Manhattan
  • Predicción: Retorna salida del prototipo más cercano

================================================================================
NOTAS IMPORTANTES
================================================================================

1. NORMALIZACIÓN: Para mejores resultados, normaliza los datos antes de usar.

2. VALOR DE K: 
   - K pequeño (1-3): Menos suavizado, más sensible a ruido
   - K grande (>5): Más suavizado, puede perder detalles

3. MÉTRICAS:
   - Euclidiana: Mejor para espacios continuos
   - Manhattan: Mejor para datos en grid o urbanos

4. CLASES EN MÍNIMA DISTANCIA:
   - Se detectan automáticamente según salidas únicas
   - Cada clase tiene un prototipo (centroide)

5. ENTRENAMIENTO:
   - Sin parámetros que ajustar, es instantáneo
   - K-NN: No requiere entrenamiento explícito
   - Mínima Distancia: Calcula prototipos en construcción

6. ARCHIVOS:
   - Codificación: UTF-8
   - Ruta relativa: Desde la carpeta del proyecto
